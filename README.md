# Misafir Terliğinin Diplomatik Dokunulmazlığı

## Resmi Uyarı

Bu depo bir şaka değildir.  
Bu depo bir şakaya benzeyen resmi evraktır.  
Gülerseniz tutanak tutulur. Tutanak da gülerse ikinci tutanak tutulur.

Türkiye Cumhuriyeti Misafir Terliği Dışişleri Genel Müdürlüğü, evlere giren her çift misafir terliğini **geçici elçi** statüsüne almaktadır. Terlik eşiği geçtiği anda Viyana Konvansiyonu yürürlüğe girer. Kimse sormaz. Sormak da ihlaldir.

## Bu Yazılım Ne Yapar?

1. Ev sahibi ve misafir adını alır.
2. Rastgele ama **resmi görünen** bir ihlal tespit eder.
3. Yaptırım uygular (cay gecikmesi, kırmızı halı, wifi harfi).
4. Dosya numarası üretir. Dosya numarası gerçektir. Dosya yoktur.

Kod **gerçekten çalışır**. Python 3 yeter. Terlik gerekmez ama tavsiye edilir.

```bash
python3 terlik_elciligi.py
```

## Hukuki Dayanak (uydurulmuştur, yine de saygı gösteriniz)

- Viyana Konvansiyonu Madde 22 — Terlik Yorumu  
- Ev Yönetmeliği Madde 0 — Yoktur ama varmış gibi  
- Misafirlik Örfü Genelgesi 1998/7 (hayalidir, bağlayıcıdır)

## Sık Sorulan Sorular

**Terlik konuşur mu?**  
Hayır. Konuşmaması icabı kabuldür.

**Kedi terliğe girerse ne olur?**  
Konsolosluk işgali. Yaptırım otomatiktir.

**Patates var mı?**  
Yok. Yasak. Konu kapanmıştır.
